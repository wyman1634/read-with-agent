# 首轮验证 · 2026-10-10

首版验证环境为 Codex。此报告评估技能产物和续读行为，不衡量读者学习收益。

## 确定性验证

- Skill frontmatter 与目录检查通过。
- 20 项 Python 单元测试通过：14 项渲染器测试、6 项 EPUB 提取测试。
- 渲染器覆盖章节导航、折叠、离线依赖、缺文件、代码与链接安全；提取器覆盖 spine 顺序、重复元数据、图像缺口、异常文件和拒绝覆盖。
- 用户实际试读页在桌面浏览器验证了搜索、展开／收起、章节导航、键盘折叠；34 个本地来源链接存在，第二章原文通过 HTTP 回查。

## 固定材料对照

两名独立执行者接受相同的《控制论与科学方法论》2005 新星版 EPUB 提取材料与请求，分别有／无 Skill。另一名评审者按六项预设内容要求核对产物和关键原文。

| 维度 | 使用 Skill | 普通 Agent |
| --- | --- | --- |
| 本次联合要求通过数 | 6/6 | 4/6 |

| 实际分析范围及图像缺口披露 | 较明确 | 分析范围披露不够精确 |
| 第二章概念及条件 | 包含信息量与意义区别 | 未展开该区别 |

| 呈现取舍 | 内容与记录较完整，也较长 | 地图更紧凑，包含笔记导出 |

计分只代表这一次输出。六项要求各自合并多个结果；只有一组对照，没有重复运行，不能估计稳定性或宣布普遍优于普通 Agent。没有可靠耗时、token 和学习效果数据。

双方首次输入的元数据提取清单都丢失了重复 creator 字段，使用 Skill 的产物因此误述元数据；用户试读副本已回查原 OPF 并修正。附带的正式 EPUB 提取器保留全部重复字段，并有对应测试。原始对照产物保留用于审计，不将事后修正冒充初次结果。

## 类型与续读回归

- 技术：只使用《Think Python》的六节摘录，检查列表别名、浅复制、参数重新绑定，提出一个尚未回答的练习；不是整书蒸馏。
- 文学：只使用《爱丽丝漫游奇境》第一章，按第一章依据解释叙事并提出开放讨论；无后续剧情输入。
- 续读：新的执行者只读取前轮文件，无聊天历史。模拟请求改选第二章 2.5、声明 2.1 感觉懂了并要求不用网页；结果恢复目标，记录自述而不认定掌握，保留未答问题，改用聊天。

独立内容评审分别通过技术 6/6、文学 6/6、模拟续读 5/5 项要求。通过数只代表上述单次产物与预设要求。技术练习尚未检验嵌套浅复制迁移；节选页面沿用了“全书地图”模板名称，正文范围仍明确限定。

这三项仅运行使用 Skill 的回归，没有无 Skill 对照。模拟续读中的反馈不是用户真实学习表现，不写入用户实际阅读进度。技术／文学页面只完成文件级检查，未作浏览器验收。

## 尚需验证

真实读者是否更容易定位重点、页面长度是否合适、讨论能否促进理解，以及中长期应用。仅书名的早期运行被用户材料更新中断，未计分；其他 Agent 兼容、自动触发准确率、手机体验和大规模对照尚未验证。
