# 蒸馏

全貌：先区分变量名和对象，再区分外层容器与内部对象，最后判断操作改变的是引用关系还是对象内容。以下内容对应本项目自编教材；图形与预测例子是 Agent 补充解释。

## 1. 赋值

教材观点：`b = a` 让两个名字引用同一对象。`b.append(...)` 改变共同的列表，所以从 `a` 也看得到。

依据：[第 1 节原文 P1–P2](source/01-assignment.txt)。本节是理解浅复制所需的前置关系。

## 2. 浅复制

教材观点：`a[:]` 新建外层列表，内部项仍引用原有对象。讨论“复制是否隔离修改”时，需要先确定修改发生在哪一层。

依据：[第 2 节原文 P1–P3](source/02-shallow-copy.txt)。

Agent 示范：先只执行下面两行。

```python
a = [{"name": "A"}]
b = a[:]
```

Agent 示意图：箭头表示引用，A、B 是两个列表，X 是同一个字典。图只回答“哪一层独立、哪一层共享”。

```text
a --> [list A] -- item 0 --+
                           |
                           +--> [dict X: name="A"]
                           |
b --> [list B] -- item 0 --+
```

`b[0]["name"] = "B"` 改变 X 的内容，两边都能看到；`b.append({"name": "C"})` 改变列表 B 的项，列表 A 不会增加一项。这是两种不同层级的操作。

待续读的完整例子如下，当前没有模拟读者的独立答案：

```python
a = [{"name": "A"}]
b = a[:]
b[0]["name"] = "B"
b.append({"name": "C"})
print(a)
print(b)
```

可先预测两行输出并指出每次操作改变了哪个对象，也可以要求 Agent 先逐行演示。是否进入第 3 节由真实讨论决定。

## 3. 重新绑定

教材观点：`b = ["B"]` 改变名字 b 的引用，没有修改它先前引用的列表。把操作分成重新绑定名字、修改外层容器、修改内部对象，可以解释三节的例子。

依据：[第 3 节原文 P1–P2](source/03-rebinding.txt)。尚未模拟本节带读；深复制留作材料之外的后续扩展。
