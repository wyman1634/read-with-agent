# 文字与简洁架构图

技术带读涉及多个对象或不同链路时默认先图后文：简短交代必要对象与情境，再给图和紧随其后的解释。输出语言跟随读者偏好。一个术语或字段用文字和完整例子已能说清时，直接推进阅读；读者明确选择纯文字时按其选择。

## 选择展示形式

| 当前需要 | 默认动作 |
| --- | --- |
| 对象包含、组件职责、调用关系、共享边界 | 用少量框、线、箭头与必要标签画静态图；一图聚焦一个问题 |
| 状态变化、前后差异 | 先用并排状态图或步骤图；需要操作才能澄清因果时，加切换状态、单步推进等少量交互 |
| 复杂架构 | 先总览后局部展开，按职责或链路拆图；优先自行绘制，现有能力确有缺口时再查找合适技能 |

复用同一案例和对象命名，按当前问题逐张展开；每图聚焦一种关系，箭头标明管理、请求、配置更新或数据共享等含义。同一对象出现在不同图中时，说明是同一对象的不同视角。读者反馈关系没讲清时，先检查图是否缺失或混合多种链路，拆出当前断点再补解释。

对象命名与原文对应，补充例子和版本差异明确标记。视觉细节用于区分有意义的关系，避免零件、阴影和实物隐喻抢占概念的重点。

## 少量交互与成本

仅加入能回答当前问题的变量和结果，例如切换就绪状态后高亮后端资格变化。先查已有图或演示，能复用时直接采用；基础简图和轻量交互在授权的带读范围内直接完成，不让读者每次选择是否画图。

需要显著延长等待、扩展成大型演示或引入额外制作工具时，先核对机制和复用机会，给出具体范围、操作与结果、成本估计及简单替代方案，让读者选择。已明确授权的范围直接执行；扩大范围再确认。选择尚未收到时，继续可以独立完成的文字讲解。

交互由用户主动开始，阅读过程中保留当前主题和状态；自动切换不作为默认。先示范，再按需要邀请读者预测改变条件后的结果并解释理由。

## 交付与续读

图形放在当前讲解旁，注明它回答的问题、原文定位，以及是原书图还是 Agent 示意图。优先使用当前界面能直接显示的图形：聊天宿主已确认支持 Mermaid 时，可直接输出 Mermaid 图；其他环境选用其支持的图片等形式。确认方式可以是宿主说明或已有实际显示反馈，无需每轮重新询问。

聊天与离线读书页分别验收。读书页由 `scripts/render_reader.py` 生成，不执行 Mermaid，也不内嵌 SVG；需要把聊天图保存到读书页时，提供受支持的图片，保留可修改来源。按其实际能力选择交付：

| 形式 | Markdown 写法与读书页行为 |
| --- | --- |
| 等宽文本简图（回退） | 放在 `text` 代码块中；当前界面无法直接显示图形、低成本成图条件不足或读者选择时采用，并说明回退原因 |
| 已生成的 PNG／JPG／JPEG／WebP | 保存到工作区，用 `[Agent 示意图：主题](visuals/topic/diagram.png)` 链接；页面点击展开，图片内嵌并可离线查看 |
| Mermaid／SVG 源文件 | 保留可修改来源；聊天可按宿主能力显示，读书页需要配套上述格式的图片，源码本身不算已显示的图 |
| 少量交互的独立 HTML | 用 `[交互演示：主题](visuals/topic/index.html)` 链接；另页打开，不自动内嵌。交付整个工作区，演示自身也应能离线运行 |

读书页尚未支持普通 Markdown 图片语法 `![说明](路径)`，图片使用上表的普通链接；每个内嵌文件上限 2 MB。优先复用已有图片或简单绘制，制作成本遵循上节规则。

独立图形及可修改源文件保存在本书工作区，例如 `visuals/<主题>/`，在相关讲解中记录路径和覆盖范围，便于复用。重新生成读书页后，实际检查图是否显示、箭头是否清楚、链接是否可用；交互只检查本轮使用的操作。没有执行的检查如实说明。文本图与内嵌图片可随单个读书页交付，独立演示还需要其文件；读书页中的续读指令仍依赖工作区的 Markdown 记录。

教学模拟与真实实验分别标明；观看、点击或 Agent 演示不能作为读者掌握的证据。通用判定在本文件维护，`preferences.md` 只保存读者的语言、展示选择及成本授权等差异；换书继续沿用技能规则。
