# 阅读工作区与续读

## 阅读根目录与偏好分层

阅读根目录容纳多本书，与单本工作区分开：

```text
<阅读根目录>/
  preferences.md      跨书公共偏好，可按技术书／文学等注明适用范围
  <书籍短名>/         单本工作区
    preferences.md    本书选择与公共项的明确例外，可省略
```

先复用用户指定路径或已有书籍目录。新书沿用已有阅读根目录和同级布局；当前目录已是阅读根目录（如 `reading/` 或有本项目明确约定）时直接建书籍子目录，在一本书内启动则沿用它所属的根目录。无约定时检查当前目录及其 `reading/`、`outputs/reading/` 中的既有工作区；都没有才回退到 `outputs/reading/<书籍短名>/`。多个根目录无法消歧时再问。已有目录直接恢复，迁移先修正当前路径与续读入口并重建页面，保留来源、历史与理解证据。

用户给出的旧路径不存在时，先检查既有阅读根目录的同名书籍目录并核对身份，再使用新位置，不按失效路径重建工作区。

公共文件采用书籍工作区祖先目录中最近的 `preferences.md`；按本次已定位的路径逐级查找，避免遍历其他书籍。没有公共文件也可续读；多书根目录首次保存公共偏好时在根目录创建，不将个人偏好存入技能安装目录。渲染器按同一约定读取，公共和本书偏好分开展示。

新增或修改偏好先判断范围，再保存：

- **公共**：跨书适用的语言、展示、互动与成本选择；只适用于技术书等类别时在公共文件标明条件。
- **本书**：具体目标、版本、实验环境、专用案例、剧透范围及本书例外。保留已有明确范围，不因一句反馈就推广到所有书。
- **范围不明**：暂存本书并注明待确认；需要决定跨书应用时再问，不为普通偏好更新阻塞当前带读。

采用顺序为当前明确要求、本书明确覆盖项、公共偏好、技能默认。只更新发生变化的项；公共更新无需复制到各书，本书文件保留公共文件相对链接及自己的差异。通用教学方法由技能维护，个人选择由偏好文件维护；目标、正文和历史证据分别留在对应工作区记录。

整理重复偏好时先完整归档原文件，再抽取公共项与本书差异；归档仅供追溯，不能作为当前偏好覆盖来源，也不改变理解状态。

文件名约定供渲染器和新会话定位，不需要额外数据库或配置系统：

```text
<本书工作区>/
  source/             原始材料和提取文本，仅本地保存
  map.md              身份、目的、材料范围、书籍结构
  distillation.md     已核对内容的分层蒸馏
  route.md            精读路线、关键原文位置、推荐下一步
  preferences.md      本书偏好、授权范围与例外（有差异时建立）
  progress.md         当前状态、相关证据与下一步的简短摘要
  history/            按单元或阶段保存的原始讨论与历史证据
  reader.html         由以上文件生成，可随时重建
```

相同书名不同版本需要区分目录或在 map 中注明版本；匹配不明时先确认。更新保留已有内容，不要用模板覆盖已填写文件。

## map.md 的最小信息

```markdown
# 书名

作者／版本：已核实信息；未知项写未确认。
阅读目的：用户目标；暂定目标标明待确认。
阅读方式：类型与深度；小说记录剧透范围。

## 材料范围
可用材料：文件或 URL，实际覆盖范围。
已读取：具体章节／节／段落；目录与简介单列。
已分析：与蒸馏对应的范围。
缺口：缺失正文或尚未读取的章节。

## 结构地图
各部分的功能和联系；仅据目录推测的关系标为暂定。

## 来源
每项来源的文件或 URL、版本、定位方法和使用范围。
```

页面公开导读可链接公开来源。私人原书路径使用工作区相对路径；发布示例前移除个人目录、原始书籍材料与阅读隐私。

技术书的 `map.md` 还保存 [technical.md](technical.md) 要求的领域关系图，与全书章节表分开：保留当前所需概念的用途、层次和关系，注明后续待展开或待核对的范围。图示只表示讲解范围，不代替真实理解证据。旧工作区缺这一层时补当前所需框架，保留原有身份、范围、章节与历史，不重建整套工作区。

## distillation.md

先短全貌，再按二级标题组织重要部分。每部分保留关键内容、理解所需条件、原文依据与待核对事项。区分作者观点、来源事实、背景补充和 Agent 推论。表格与结构图在能帮助理解时使用；未经验证的主题不能靠标题包装成“本书核心结论”。

## route.md

关键原文用章／节／可核对页码或段落定位。当前需要展示的原文放在本工作区 source 中，以相对链接引用；页面将其变为就地折叠框。优先准备对应选段，保留原定位，避免把未获准的文学剧情随完整底本嵌入。每个阅读单元记录阅读理由、重点问题、详略建议。尾部列出明确下一步；不以用户尚未做的计划填成已完成。

技术路线的当前入口同时指向领域关系图的相关位置、必要前置及缺失时的补读入口。补框架时保留被暂缓的原下一步，框架清楚后再接回；详细规则以 [technical.md](technical.md) 为准。

## progress.md

作为续读入口，保留书籍身份与版本、目标、更新时间、当前单元、与下一步相关的理解证据和缺口、来源限制、明确下一步与定位指针。常规摘要尽量控制在一屏至约60行；必要缺口优先于机械行数。长期未涉及的证据和原始对话移到 `history/`，以主题与路径列索引；正文增长到必须滚过历史才能找到下一步时及时整理。

两层 `preferences.md` 只保存当前选择与适用范围；按上述规则分类，有变化时更新对应项。书籍目标在 progress 中保留权威记录，本书偏好可简短引用；解释正文与历史原话留在 distillation、history。没有本书差异时可省略本书偏好文件，公共偏好仍生效。

整理旧工作区时，先完整保存原记录，再提炼当前摘要；保留可回查的实际原话、待解问题与证据边界。归档标明保存日期、覆盖范围及其历史性质，旧偏好不覆盖当前选择。迁移不改变理解状态。下一轮更新当前摘要并把新增讨论写入对应历史单元，避免每轮复制整个进度文件。

技术书额外记录实际提交的代码／预测／实验及反馈；区分：

| 状态 | 证据 |
| --- | --- |
| 已介绍 | Agent 已解释，用户尚未展示理解 |
| 自述理解 | 用户说理解了，尚无独立表现 |
| 有证据理解 | 实际解释、应用或讨论支持这个范围的理解 |
| 仍有缺口 | 具体误解或待检验之处 |
| 已跳过 | 用户选择跳过，能力尚未验证 |

不用统一掌握百分比或每本书固定考试分数。

## 新会话续读

1. 定位用户指定书籍工作区，先读最近祖先目录的公共 preferences、本书 preferences（如有）和简短 progress。旧进度较长时先看开头、标题索引与下一步，按需取相关段落；不要先遍历 history、其他书的偏好或全文蒸馏。
2. 根据摘要确认身份、版本、目标与下一步；信息不全时补读 map 的相关段落。路线按当前入口加载，历史仅在追溯证据、处理矛盾或恢复缺失上下文时加载。
3. 按标题或定位指针读取下一步所需的蒸馏与原文。技术路线缺少当前领域关系框架时，按 technical.md 补图并调整前置，不把已有章节表视作框架已全。有文件路径但材料丢失时说明缺口，仍可继续有依据的回顾。较长 map、route、distillation 同样先定位后读取；HTML展示完整资料不意味着 Agent 每次需要加载全文。
4. 完成一个讨论单元后更新记录与页面。聊天与记录有冲突时采用用户最近的明确纠正。

若以前没有记录，可以依据当前可见对话恢复，并标明恢复依据；对看不到的旧会话不制造记忆。
