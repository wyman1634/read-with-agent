# 来源准备与覆盖范围

## 全文或节选

优先使用环境已有的阅读、提取工具。Markdown/TXT 直接阅读；PDF 使用现有 PDF 工具或 `pdftotext -layout`，扫描件需要 OCR 并抽样校对；EPUB 可以运行技能附带的标准库辅助：

```bash
python3 <技能目录>/scripts/extract_epub.py <原书.epub> <本书工作区>/source
```

辅助按 spine 顺序提取正文并保存来源指纹、原章节定位与图片缺口；已有非空输出目录默认拒绝覆盖。对原图与图片公式按当前阅读需求回查原 EPUB，避免把未提取内容当成已经分析。也可使用环境已有工具，但应保留阅读顺序。

保留原始材料与提取文本，检查目录、正文起止、乱码和公式／表格缺损。只在原文实际存在时引用页码；PDF 页序与印刷页码不同要注明。无页码可用章节、小标题、段落序号或原文短语定位。代码和公式保留原始格式，疑似提取错误须回查。

长书先核对结构，再按相关性分批读取正文。记录本轮确实读取的范围，逐渐扩大覆盖；全文在磁盘上不等于 Agent 已读完。已有地图允许快速导航，但正文结论仍需要实际读取。

## 仅书名

先核实作者与版本，优先作者／出版社提供的目录、试读与图书馆书目信息。公开书评可补充不同视角，但不能代替原书证明作者论证。无法访问网页或工具不可用时说明依据限于当前材料，不编造已搜索或已阅读全文。

提供书目资料支持的结构导读、暂定阅读路线与必要背景。对未读章节只注明主题或待核对的问题；不根据章节标题补写作者的例子、结论或论证。需要深入原文时指出所需的具体章／节，可让用户提供其持有的原文或合法试读。

每项来源记录 URL／文件、版本、范围和定位。不同版本不要自动拼接为同一本完整书。直接引用保持短而准确，解释尽量自行概括；公开示例只使用适合分享的材料。

## 内容分层

- 作者观点：读过的具体文本支持，并能返回位置。
- 来源事实：书目、目录、试读直接证明的内容。
- 补充解释：帮助理解的背景／类比，明确与书中原例不同。
- Agent 推论：基于现有材料的判断，列明条件和待核对处。

在内容所在处标注范围或不确定性，避免只在页尾总免责声明后把正文写成确定的整书结论。
